# Contact Book (Java)

A simple Java-based **Contact Book** that allows users to manage contact information through a menu-driven console application.

## Features

- Add contacts
- View all contacts
- Search contacts by ID
- Update contact information
- Delete contacts
- Store name, phone number, and email
- Simple menu-driven interface

## Technologies Used

- Java
- ArrayList
- Scanner
- Object-Oriented Programming

## Project Structure

```text
contact-book-java/

```

## How to Run

Compile:

```bash
javac ContactBook.java
```

Run:

```bash
java ContactBook
```

## Sample Menu

```text

1. Add Contact
2. View Contacts

4. Update Contact
5. Delete Contact
6. Exit
```
